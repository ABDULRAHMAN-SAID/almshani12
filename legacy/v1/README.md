# منصّة — منصّة تعليمية عربية متكاملة

منصّة تعمل عبر الشبكة تجمع ثلاثة مصادر دخل في مكان واحد:

| المحور | الوصف |
|---|---|
| 🔴 **حصص مباشرة مدفوعة** | حجز مقاعد بسعر محدّد، قاعة بثّ داخلية فيها دردشة لحظية، رفع يد، تسجيل حضور، ومسابقات تفاعلية بنقاط سرعة |
| 🎬 **دورات مسجّلة** | أقسام ودروس (فيديو/مقال/PDF/صوت)، تتبّع تقدّم، اختبارات مصحّحة آلياً، أسئلة وأجوبة، وشهادات قابلة للتحقّق |
| 📖 **ملخّصات كتب مدفوعة** | مقتطف مجاني يظهر للجميع ومحتوى كامل محميّ خلف جدار الدفع، مع نسخ PDF وصوتية، وقارئ داخلي بملاحظات شخصية |

## التشغيل

```bash
npm install
npm run seed      # بيانات تجريبية جاهزة
npm start         # http://localhost:3000
```

## الإضافات المدمجة

بجانب المحاور الثلاثة الأساسية:

- **باقات اشتراك** شهرية وسنوية — وصول غير محدود بدل الشراء عنصراً عنصراً
- **محفظة ورصيد** مع دفتر حركات كامل (شحن، شراء، استرجاع، أرباح، مكافآت)
- **كوبونات خصم** بنسبة أو مبلغ، بحدّ استخدام وتاريخ انتهاء ونطاق تطبيق
- **نظام إحالة** برابط ورمز ومكافأة تلقائية عند أول شراء للمدعو
- **اختبارات وشهادات** — شهادة تصدر بعد إكمال الدورة واجتياز اختباراتها، ولها صفحة تحقّق عامة برقم تسلسلي
- **أسئلة وأجوبة** لكل دورة مع اعتماد الإجابة الصحيحة وشارة للمعلّم
- **تقييمات موثّقة** — لا يُقبل التقييم إلا ممّن اشترى فعلاً
- **لوحة معلّم** كاملة: محرّر دورات ودروس، جدولة حصص، محرّر ملخّصات، تحليلات أرباح، وطلبات سحب
- **لوحة إدارة**: اعتماد المعلّمين، مراجعة المحتوى قبل النشر، إدارة الطلبات والاسترجاع، صرف السحوبات، وسجلّ عمليات
- **إشعارات لحظية** عبر Socket.IO، ملاحظات شخصية، قائمة مفضّلة، وسلة مشتريات

## البنية

```
server/
├── index.js            نقطة التشغيل، الأمان، والمهام الدورية
├── config.js           كل الإعدادات من متغيّرات البيئة
├── db/                 المخطّط، الاتصال، والبيانات التجريبية
├── middleware/         المصادقة، التحقّق، ومعالجة الأخطاء
├── services/           منطق العمل: الصلاحيات، الشراء، الدفع، المحفظة، الإشعارات
├── routes/             واجهات REST
└── realtime/           قاعة البثّ المباشر والمسابقات (Socket.IO)

public/
├── index.html          هيكل التطبيق أحادي الصفحة
├── css/app.css         مبنيّ من src/app.css عبر Tailwind
└── js/
    ├── api.js          طبقة الاتصال مع تجديد الجلسة تلقائياً
    ├── store.js        الحالة المشتركة
    ├── router.js       موجّه المسارات مع حراسة الصلاحيات
    ├── ui.js           مكوّنات العرض المشتركة
    └── pages/          صفحات التطبيق
```

**التقنيات:** Node.js + Express + SQLite (better-sqlite3) + Socket.IO في الخلفية، وواجهة JavaScript خالصة بوحدات ES مع Tailwind مبنيّ محلياً — بلا خطوة تجميع للواجهة وبلا اعتماد على CDN خارجي.

## الدفع

طبقة الدفع مجرّدة خلف واجهة واحدة (`server/services/payments.js`) وتدعم أربع وسائل:

| الوسيلة | الاستخدام |
|---|---|
| `mock` | بوابة محاكاة كاملة تعمل بلا مفاتيح — للتطوير والعرض |
| `wallet` | خصم فوري من رصيد المستخدم |
| `manual` | تحويل بنكي يعتمده المدير من لوحة الطلبات |
| `stripe` | بوابة حقيقية عبر REST — تُفعَّل بضبط `STRIPE_SECRET_KEY` |

**للتحويل إلى الإنتاج:** ضع مفاتيح Stripe في `.env`، أضف `stripe` إلى `PAYMENT_PROVIDERS`، واحذف `mock`، ثم وجّه الـ webhook إلى `POST /api/webhooks/stripe` (التوقيع يُتحقَّق منه مع رفض الطوابع الزمنية الأقدم من خمس دقائق).

عند نجاح أي عملية شراء يُنفَّذ كل ذلك في معاملة واحدة: منح صلاحية الوصول، تسجيل الالتحاق، قيد حصّة المعلّم بعد العمولة، خصم الكوبون، ومكافأة الإحالة — وهي عملية آمنة للتكرار فلا يُعالَج الطلب مرتين.

## ملاحظات أمنية مطبَّقة

- المحتوى المدفوع لا يغادر الخادم إطلاقاً لغير المالك: محتوى الملخّص، روابط الدروس، ورموز قاعات البثّ كلها محجوبة على مستوى الاستعلام لا الواجهة
- الحصة المجانية تظلّ بمقاعد محدودة — الدخول يتطلّب حجزاً فعلياً لا مجرّد سعر صفري
- إجابات الاختبارات الصحيحة لا تُرسَل للمتصفّح قبل التسليم
- رموز التجديد تُخزَّن مُجزّأة (SHA-256) وتُدوَّر عند كل استخدام، وتُبطَل كل الجلسات عند تغيير كلمة المرور
- كل مدخلات المستخدم تمرّ عبر مخطّطات Zod، وكل النصوص تُهرَّب قبل العرض
- رفع الملفات مقيّد بالنوع والحجم مع أسماء عشوائية وامتدادات مُطهَّرة
- رسالة موحّدة عند فشل الدخول أو استعادة كلمة المرور حتى لا تُكشف البُرد المسجّلة
- حدود طلبات على مستوى الواجهة كلها وعلى مسارات المصادقة خصوصاً
